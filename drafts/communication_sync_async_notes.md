# 同期・非同期コミュニケーション 整理メモ

記事執筆のための議論の途中経過をまとめたもの。

---

## 1. 同期・非同期コミュニケーションの特徴

### 同期コミュニケーションの特徴

- 応答が即時である
- 非言語情報（声色、表情、間、うなずき）が伴う
- 参加者全員の時間を同時に拘束する
- 記録性が弱い（ツールで補わない限り揮発する）
- 思考の速度に引っ張られる（考えが浅いまま発言しがち）
- 共創・即興的な発想がしやすい
- 軌道修正がその場でできる
- 関係性・信頼の構築に効く
- 雑談や沈黙の共有が生まれる
- 誰が話し誰が黙っているかという場の力学が見える
- **参加者の事前準備度に生産性が依存する**
- 準備不足だと「持ち帰ります」が頻発する
- 感情や温度感が伝わりやすい
- 議題が発散しやすい（脱線しやすい）
- 一対多、多対多のダイナミクスが発生する
- 声の大きい人に議論が引っ張られやすい
- 時差のあるメンバーを排除する
- 物理的/精神的な疲労を生みやすい（連続すると消耗）
- スケジュール調整のオーバーヘッドが発生する
- 参加しなかった人への情報共有が別途必要になる

### 非同期コミュニケーションの特徴

- 応答に時間差がある
- テキスト中心で情報量が限られる
- 各自のリズム・集中時間を尊重できる
- 書いた瞬間に記録として残る
- 検索・参照が可能
- 推敲できる（思考を整理してから出せる）
- **書き手の文章化・可視化能力に強く依存する**
- **文章化・構造化が得意な人は少ない**
- 読み手の読解力にも依存する
- 誤読されても即座に修正できない
- 図解・スクリーンショット・動画などの併用が有効
- 往復回数が多くなると非効率化する
- 探索的・発散的な議論に向かない
- 感情や緊急度が伝わりにくい
- 沈黙が「無視」か「熟考中」か判別できない
- タイムゾーンを超えて機能する
- 参加者数をスケールさせやすい（100人への共有も同じコスト）
- 関係性の構築には弱い
- 新規参加者が過去の文脈にアクセスできる
- 意思決定プロセスの透明性・トレーサビリティが高い
- 返信しない自由がある（通知疲れとの表裏）
- 「既読スルー」問題が発生する
- 反射的に返信すると非同期の利点が失われる
- 書くことに時間がかかる（1対1の口頭で30秒の話が、文章だと5分）
- 組織内の文章力格差が発言力格差に直結する

### 両者に関わる横断的な観点

- 使用するツール（Slack, Zoom, PR, Doc, メール等）で性質が変わる
- 運用ルール（返信期待時間、絵文字リアクション文化等）で性質が変わる
- 組織文化（trust levelや心理的安全性）が前提になる
- ハイブリッド形態が存在する（録画された会議、ライブドキュメント共同編集、Slack huddle等）
- AIの介在で性質が変わりつつある（要約、文章整形、議事録生成）
- 非同期の質が後続の同期の質を決める（事前資料→会議）
- 同期の質が後続の非同期の質を決める（合意形成→各自の実装）
- チームの物理的配置（同一拠点/リモート/ハイブリッド）が前提を変える
- 議題の性質（探索型/収束型、感情的/論理的、緊急/非緊急）で適性が変わる
- 参加人数で適性が変わる（2人なら同期が軽い、20人なら非同期が軽い）
- キャリア段階で適性が変わる（ジュニアは同期での学びが多い、シニアは非同期で自走）

## 2. 目的・機能による向き不向き

### 指示・依頼系

| 種類 | 向き | 理由 |
|---|---|---|
| 指示 | 非同期寄り | 記録が残る、受け手が自分のタイミングで着手できる |
| 依頼 | 非同期寄り | 断る余地を与えるには時間が必要。口頭だと圧がかかる |
| 命令 | どちらでも | 緊急性次第。インシデント対応は同期、通常は非同期 |
| 委任 | 同期+非同期 | 目的の握りは同期、詳細は非同期で |
| 催促 | 非同期寄り | 記録が残ることで軽いプレッシャーになる |

### 共有系

| 種類 | 向き | 理由 |
|---|---|---|
| 通知・アナウンス | 非同期 | 大人数、記録必須、受け手の時間を拘束しない |
| 周知・徹底 | 非同期ベース+同期で補強 | 文書で配布し、重要なら会議で念押し |
| 報告 | 非同期 | 定期・定型のものは完全に非同期でよい |
| 情報共有 | 非同期 | 見る/見ないは受け手の判断 |
| ナレッジ共有 | 非同期が基本、同期も有効 | ドキュメントが基本、勉強会という同期も価値あり |

### 相談・意思決定系

| 種類 | 向き | 理由 |
|---|---|---|
| 相談 | ケースバイケース | 論点が明確なら非同期、モヤモヤしてるなら同期 |
| 議論 | 同期寄り | 往復回数が多くなる、温度感が重要 |
| 意思決定 | 非同期で準備→同期で決める | 情報整理は非同期、最終判断は同期の方が早い |
| ブレインストーミング | 同期 | 発散には反応速度が必要、刺激し合う |
| レビュー・フィードバック要求 | 非同期 | PRレビューが代表例、じっくり見る時間が必要 |

### 確認系

| 種類 | 向き | 理由 |
|---|---|---|
| 質問（事実確認） | 非同期 | 1往復で済む、記録が残る |
| 質問（探索的） | 同期 | 何を聞けばいいか自体が不明確な場合 |
| 認識のすり合わせ | 同期寄り | ズレの発見は対話の中で起きる |
| 承認依頼 | 非同期 | Go/No-goは書面で十分 |

### 感情・関係性系

| 種類 | 向き | 理由 |
|---|---|---|
| 雑談 | 同期 | テキストの雑談は雑談ではない別物 |
| 称賛・感謝 | 両方併用 | 同期は温度が伝わる、非同期は記録に残る |
| 謝罪 | 同期 | 温度感なしの謝罪は火に油 |
| ポジティブフィードバック | 非同期でも可 | 書面で残ると本人の自信になる |
| ネガティブフィードバック | 同期一択 | テキストは冷酷に見える、誤解のリスク大 |
| 評価の伝達 | 同期 | 双方向の対話が必要 |
| 叱責・注意 | 同期 | 感情の扱いを相手任せにできない |
| 励まし・共感 | 同期寄り | 沈黙や間に意味がある |

### 交渉系

| 種類 | 向き | 理由 |
|---|---|---|
| 交渉 | 同期 | 相手の反応を見ながら動く |
| 説得 | 同期 | テキストで意見は変わらない |
| 調整（事務的） | 非同期 | 日程調整などは非同期が効率的 |

### 学習・伝承系

| 種類 | 向き | 理由 |
|---|---|---|
| 教育・指導（知識） | 非同期ベース | ドキュメント・動画で反復学習できる |
| 教育・指導（スキル） | 同期 | ペアプロ・モブプロが代表例 |
| オンボーディング | 両方必要 | 文脈は同期、情報は非同期 |
| メンタリング | 同期 | 関係性ベース、問いかけの往復 |
| 問いかけ | 同期 | 相手が考える様子を見たい |

### 記録・参照系

| 種類 | 向き | 理由 |
|---|---|---|
| 記録 | 非同期一択 | そもそも非同期の副産物 |
| 文書化 | 非同期一択 | 書くこと自体が非同期行為 |

## 3. 向き不向きから浮かび上がるパターン（仮説）

1. **感情が絡むほど同期寄り**（謝罪、ネガフィードバック、叱責）
2. **情報の伝達・記録が主目的なら非同期寄り**（通知、報告、記録）
3. **探索的・発散的なら同期寄り**（ブレスト、探索的質問、議論）
4. **収束的・確認的なら非同期寄り**（承認、事実確認、レビュー）
5. **「準備は非同期→決定は同期→記録は非同期」の連鎖**が多くの意思決定で発生

---

## 4. 議論の中で出てきた重要な気づき

- 同期/非同期は二項ではなく、複数の軸（応答時間・情報量・記録性・認知負荷）で連続的に捉えるべき
- 同期には**参加者の事前準備**という隠れた前提条件がある
- 非同期には**書き手の高い文章化・可視化能力**という前提条件がある
- 文章化能力が得意な人は少なく、非同期偏重は**組織内の文章力格差を発言力格差に変換**する
- 両者は使い分けるものではなく、**それぞれの前提条件を理解して組み合わせる**もの
